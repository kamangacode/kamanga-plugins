# REQ-BOOKING-001 : Annulation de réservation par le client

## Description

Permettre au client d'annuler une réservation confirmée avant un délai limite (24h), avec remboursement automatique.

## Contexte métier

Demande client récurrente. Réduit le support manuel (15% des tickets en mars 2026).
